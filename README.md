# 💼 HustleGuard: The Offline AI Proposal & Contract Voice-Engineer

HustleGuard is a 100% offline, privacy-first AI agent designed for freelancers, side-hustlers, and small business owners built for the **Hacktoberfest 2026 Open-Source AI Challenge: Week 2 (Side Hustle)**. It generates legally-clear freelance contracts and highly compelling project proposals locally on your machine—ensuring client agreements and breakthrough business ideas stay entirely safe from third-party cloud data harvesters.

---

## 🚀 Key Features
* **100% Local Guarded Inference:** Powered entirely by Google's open-weight `gemma2:2b` via the Ollama engine, running completely air-gapped on `localhost:11434`.
* **Private & Secure Client Onboarding:** Client names, financial breakdowns, and project milestones never leave the developer's local storage environment.
* **Hands-Free Audio Budget Streaming:** Implements a native, offline audio streaming layer that vocalizes crucial milestones and financial boundaries directly to your headphones, eliminating screen-time strain.

---

## 🛠️ Tech Stack & Dependencies
* **Language:** Python 3.10+
* **AI Architecture Provider:** Google Gemma Open-Weight Ecosystem (`gemma2:2b`)
* **Local Inference Pipeline:** Ollama Linkage API
* **Audio Layer:** Native Cross-Platform OS System Speech Sub-process

---

## ⚙️ Installation & System Configuration (Step-by-Step)

### 1. Initialize the Open-Weight AI Core
Download and activate the desktop local engine from [ollama.com](https://ollama.com). Once running, open your system terminal and pull down the verified Google model architecture weights:
```bash
ollama run gemma2:2b
```

### 2. Prepare the Python Environment
Open your terminal inside the project folder directory and establish the core execution package libraries:
```bash
python -m pip install ollama
```

### 3. Deploy the Side-Hustle Automation Core
Launch the runtime script using the following Windows CMD command to generate your assets and hear your local vocalized audio stream:
```bash
python app.py
```

## 🔓 Why Open Innovation Matters for HustleGuard
HustleGuard stands as a proof-of-concept for why open innovation is crucial for modern independent contractors:
1. **Zero Operating Overhead:** Proprietary API endpoints charge by the token. By running open weights on regional hardware, the operational cost of scaling your side hustle drops to absolute zero.
2. **Absolute Intellectual Property Protection:** Elevating proprietary industrial codebases or custom business agreements to remote centralized clouds breaks non-disclosure policies. Open innovation keeps sensitive data local on your system memory.
